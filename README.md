# YouTube X

Улучшенный YouTube-клиент для Android с поддержкой старых версий, воспроизведением в фоне, загрузчиком, Gemini и другими функциями.

## Особенности
- Воспроизведение в фоне при сворачивании
- Загрузчик видео и аудио
- Блокировка рекламы
- PiP режим
- Gemini суммаризация
- Русский интерфейс
- Оптимизированная производительность

## Сборка
Откройте проект в Android Studio и соберите APK.

Исходный код основан на открытом проекте с изменениями для YouTube X.
